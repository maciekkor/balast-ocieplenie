# Balast i Ocieplenie

Kalkulator balastu i ocieplenia dla nurków, który uczy się z Twoich ocen po nurkowaniach.
Działa w przeglądarce, można go dodać do ekranu głównego telefonu i działa bez internetu.
Wszystkie dane zostają w telefonie użytkownika (pamięć przeglądarki) — nic nie jest wysyłane na serwer.

## Publikacja na GitHub Pages

1. Utwórz repozytorium, np. `balast-ocieplenie`, i wrzuć do niego **zawartość** tego folderu
   (`index.html`, `manifest.webmanifest`, `sw.js`, `.nojekyll`, folder `icons/`).
2. W repozytorium: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   gałąź `main`, folder `/ (root)`, **Save**.
3. Po minucie strona działa pod adresem `https://<użytkownik>.github.io/balast-ocieplenie/`.

## Dodanie do ekranu głównego

- **iPhone (Safari):** otwórz adres → przycisk Udostępnij → **Do ekranu początkowego**.
- **Android (Chrome):** otwórz adres → menu ⋮ → **Dodaj do ekranu głównego** / **Zainstaluj aplikację**.

## Aktualizacje

Po wgraniu nowej wersji telefony pobiorą ją przy następnym otwarciu z dostępem do sieci.
Dane użytkowników zostają (są zapisane w przeglądarce, nie w plikach aplikacji).

## Przenoszenie danych

Profil → Kopia zapasowa → **Kopiuj do schowka**, a na drugim urządzeniu → **Wczytaj wklejoną kopię**.
